# LineupOS

A simple, mobile-first booking and front-desk tool for small surf schools, starting in Da Nang, Vietnam.

## What's here

- `index.html`: a clickable prototype of the guest booking flow and the owner dashboard. It uses sample data only: nothing is saved, booked or sent.

## Deploying

Netlify deploys this repo automatically. There is no build step; the site is served as-is from the repo root.
